## 最终修改

- 5103 四个关节 PID 共用一个 `servo_0` 输入，禁用多余的三个舵机输出，
  与单舵机机构的指令关系一致。静态全行程和悬停折叠测试均通过。
- 图像解码、识别及 PNG 保存移至独立进程，通过有界队列发送最新测量。
  视觉进程异常、旧测量、关节、姿态和接触保护均保留。
- OpenCV 从本机默认 28 线程限制为 1；图形默认半速运行，速度和阶段计时同步换算，
  使用较小的无抗锯齿窗口，限制预览帧率和数值库线程。增加运行互斥锁。
- 仅在 5103 将三个角速度控制增益系数设为 0.2，避免本轮实验中观察到的姿态振荡。
  原机型与实物参数未修改。
- 对中使用相对门平面的横向偏差，包含相机前向安装偏置；门前暂停时修正偏航。
  折叠后在距门平面约 0.95 m 处复核，使用多行边缘均值改善像素量化，
  垂直裁切时保持此前测得的高度。没有扩大横向预算或放宽到位条件。
